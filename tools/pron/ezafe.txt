# =============================================================================
# FarsiGo — ezafe linker (نشانهٔ اضافه) for the bundled audio
# =============================================================================
# Persian links a noun to a following adjective / name / possessor with a short
# -e: "šab-e yaldâ" (شب یلدا), "nân-e tâze" (نان تازه). eSpeak-NG only produces
# it when the text spells it out, so the pairs below are synthesised with a
# kasra (ـِ) written in:  شبِ یلدا → ʃab-e jaldâ.
#
# Format:  <how it appears in the app> <TAB> <how it should be spoken>
# Rules of thumb: add an entry when a noun is followed by its adjective, by a
# name/possessor (شب یلدا، گلستان سعدی), or by "این/آن" (آشپزِ این رستوران).
# Do NOT add one between a pronoun/preposition and a noun (تو بهترین…, از کرج).
#
# Rebuild the affected clips:  python3 tools/build_audio.py --only-missing
# Listen to one:               pnpm? no — run tools/pron_rules.py "شب یلدا"
# =============================================================================
